Adds an Options menu to the structured search table on the subscriptions list page. It holds the table settings, the search settings (advanced nested search and retrieval), the CSV download and a bulk edit mode. The search settings and export are removed from the table settings modal, and the "Show match details" setting is removed. The bulk edit mode adds a selection checkbox to every row; it is a mock for now and does not offer any bulk edit actions yet.
