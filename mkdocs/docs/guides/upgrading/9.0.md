# 9.0 Upgrade Guide

This guide describes the changes to account for when upgrading `@orchestrator-ui/orchestrator-ui-components` from to 9.0

## Compatibility with Orchestrator Core

Orchestrator UI Library 9.0 introduces a new way to search to the subscription list page. It depends on changes in 
the backend introduced in version 5.4.

See the [Core 5.0 upgrade guide](../../../orchestrator-core/guides/upgrading/5.0.md) for the backend migration steps.
